# FIKORU Web

Tienda escalable construida con Next.js, TypeScript y App Router.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir http://localhost:3000

## Editar el negocio

- Productos y precios: `data/products.ts`
- WhatsApp, Instagram, Facebook y dirección: `config/site.ts`
- Colores y estilos: `app/globals.css`
- Imágenes: `public/assets`
